Install

  1. Download the .fap file of the app you want.
  2. Copy it to the apps folder on the Flipper's SD card, for example with qFlipper (File manager) or the Flipper mobile app.
  3. Or build it yourself from the source with uFBT: pip install ufbt, then run ufbt in the app folder.
  4. On the Flipper, open Apps and start it.

The apps were built against the official firmware API 87.1. A different firmware may not run them.
